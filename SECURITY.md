# Prompt and data handling

Prompts and context can contain customer information, code, credentials, or private plans. Use approved providers for the data involved. Do not reduce context by removing requirements, safety constraints, or facts needed for correct work.

Evaluate prompt changes against representative tasks. Compare output quality and error rates alongside token count; lower token use alone does not show a useful result. Protect examples and evaluation data from accidental disclosure.

No prompt or savings method in this repository was validated during this documentation review. Report vulnerabilities privately through GitHub if enabled or contact the maintainer privately.
